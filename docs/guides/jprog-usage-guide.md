# Using JProg

This is about the web page: [Home / Sheets](/jprog) and
[Settings](/jprog/settings). JProg is manual sheet layout and G-code
emission for router programs — it is standalone. Emitting a program here
does not queue or update AutoCAM or Fusion AutoCAM, and nothing from
AutoCAM or Fusion feeds into JProg automatically either.

## Sheets

A sheet is one piece of stock: a width, height, and thickness. From
JProg Home you can search, create, rename, delete, and open sheets.
Opening a sheet takes you into the sheet editor.

## Coordinate system

Sheet zero is the **lower-right** corner, not the lower-left. X runs
negative to the left of that corner, and Y runs positive upward from it.
Zero your machine at the sheet's lower-right corner to match. This is
JProg's own convention — the opposite corner from most other Hub CAM
tools — because it matches the legacy JProg tool this feature replaces.

## Adding parts to a sheet

Parts can come from several sources:

- **Uploaded files** — a `.ngc` or `.tap` program you upload directly.
- **The parts library** — reusable parts uploaded once and placed on
  multiple sheets. Upload all suffix variants for a part together (for
  example the cut program and its `_holes` variant); the final
  underscore suffix becomes that variant's emission group, matching
  legacy JProg's suffix workflow.
- **Manufacturing Files** — programs attached to a manufacturing request.
- **Completed AutoCAM jobs** — G-code already generated by AutoCAM, brought
  in as a starting point. Bringing a job in this way is one-directional:
  JProg does not write back to the AutoCAM job or mark it as used.

Once a part is placed you can move, rotate, and duplicate it, add holes,
and use Measure to check spacing before emitting.

## Holes

Added holes use the bundled JProg thickness program. A hole only emits
into the final output when it carries the `holes` suffix — placing a hole
without that suffix leaves it visible in the editor but out of the emitted
program.

## Emitting G-code

Use **Emit G-code** from an open sheet. The output format — LinuxCNC
`.ngc` or WinCNC `.tap` — follows the sheet's program type, not a
per-emit choice. Review the output in the Output Editor before emitting
if you want to check it first.

Emitted output is saved to Manufacturing Files, under
`JustinProgOutput/YYYYMMDD/` — a new dated folder is created automatically
the first time something is emitted that day.

## Settings

- **Coordinate system** — confirms the lower-right-corner convention above.
- **Part library** — the upload/suffix workflow described above.
- **Output location** — the `JustinProgOutput/YYYYMMDD/` destination.
- **Hole programs** — which bundled program drives hole emission and the
  `holes` suffix requirement.

## Workflow boundary

JProg is intentionally standalone. It does not queue work in AutoCAM or
Fusion AutoCAM, and completed AutoCAM jobs brought into JProg are a
one-time copy, not a live link. Treat each tool's output as final for that
tool.
